# 标准正向撰写 · anima-prompt-writer

> 正向撰写（把画面需求写成提示词），不反推、不依赖数据集——**以本文件的「标签顺序 + 空间构图」规则为唯一标准**。产出就是给 TK 批量注入节点（TK Prompt Batch）用的批次文件。

## 何时使用

- 用户要「写提示词 / 出图 prompt / 批量生图 / 一组图 N 张」时
- 需要把画面想法转成稳定出图的提示词串
- 需要写入 ComfyUI `input/prompts/` 供 TK Prompt Batch 节点直接加载

## 一、生成规则（铁律，每条都不能省）

### Section 1：标签顺序（10 段，必须按此顺序排列）

1. **质量**：`masterpiece, best quality`
2. **美学**：`score_9, score_8`（Anima 官方美学分）
3. **时代**：如 `year 2025, newest`
4. **Meta**：`highres, official art` 等
5. **安全**：`{safe, sensitive, nsfw, explicit}`（必须如实；不确定时按更严的报）
6. **人数**：如 `1girl, 2girls`
7. **角色名**：完整角色名（如 `gotoh hitori`）
8. **系列名**：完整作品名（如 `bocchi the rock!, kessoku band`）
9. **画师标签**：一律 `@` 前缀（如 `@abpart`）；无指定画师可省略
10. **通用标签**：视觉细节（发型/眼睛/服装/姿势/背景/动作）

- **顺序即法**：角色/系列/画师必须排在通用标签之前。
- 缺哪一类就跳过哪一段，**不改变其余顺序**。

### Section 2：空间构图句（"Composition"，必写，英文 ≤60 词）

一段简洁陈述，**必须融合**：
- **视角/机位**：相机角度（`side view` / `low angle` / `from above` / `eye level` 等）
- **身体与环境的接触方式**：如 `hips resting on a ledge`、`leaning back against a wall`

### 约束（违反即返工）

- **无权重语法**：禁 `(tag:1.2)` / `{tag}` / `[tag]`，需要强调用近义并列。
- **全串只用逗号连接**：禁句号/分号/冒号（Anima/TK 节点解析铁律）。
- **不带小标题输出**：不要打印「Section 1」「标签1」等词头，直接给标签串。
- **安全如实**：构图暗示性较强（如强调臀部/胸口/露肤）时写 `sensitive` 或 `nsfw`。
- 只给**正向 prompt 串**；负向/LoRA/参数不写。
- 画师信息必须来自用户提供的资料，不要凭空编造真实画师。

### 输出格式（严格照抄形状 → 见「二、落盘规范」落地为批文件）

```
[标签1], [标签2], [标签3], [标签4], [标签5], [标签6], [标签7], [标签8], [标签9], [标签10]

[空间构图句；英文 ≤60 词]
```

## 二、落盘规范（写对目录 + 格式，节点才能吃）

### 目标目录

优先写 **ComfyUI 的 `input/prompts/`**：

- 通用：`<ComfyUI安装目录>\input\prompts\`
- TK Prompt Batch 节点「选择文件…」/「🔄 最新」会自动枚举 `input/` 与 `input/prompts/`

如果无法确认本机 ComfyUI 路径，就按 `<ComfyUI安装目录>\input\prompts\` 描述，并让用户用节点「选择文件…」确认。

### 文件名

`数字序号_内容描述_日期.txt`，例如 `01_standard_sfw_2026-08-20.txt`

### 文件结构（每组 = 标题行 + 一行提示词）

```txt
## 组1 · 单人日常 · 教室窗前
# 可选注释（# 开头，解析会跳过）
masterpiece, score_9, year 2025, highres, safe, 1girl, [角色], [系列], [通用标签...], [空间构图句（视角+身体接触环境）]
相机: from the side, low angle

## 组2 · 双人 · 海边黄昏
masterpiece, score_9, year 2025, highres, safe, 2girls, [角色A], [角色B], [系列], [通用标签...], [空间构图句]
```

> 提示词与构图句**合并成同一行**（正是你生成的标签串 + 构图句，用逗号接上）。

### 标题行（三种任选，全文件统一用一种）

- `## 组N · 标题`（推荐：段内内容合并为一条完整提示词）
- `【N】标题`
- `01 标题`（数字序号：段内每行算一条）

### 落盘前自检（逐条过，全过才交付）

1. 每组正片 = **一行**，全串**仅逗号连接**（禁句号/分号/冒号）
2. 标题行是 `## 组N · 标题` / `【N】` / `01 序号` 之一
3. `#` 开头是注释；**说明文字禁止以数字+点开头**（会被当成 01 序号标题，污染分组）
4. 可带 `相机: 机位` 行（随组生效，不计入提示词）
5. 不带 `区域:` / `背景:` / `人物:` 行（区域控制已停用，写了会干扰）
6. 文件 UTF-8 编码
7. 角色名/系列名各只出现一次、安全标签如实、画师按用户资料

## 三、与 TK Prompt Batch 节点配合

- 节点读文件 → 每组合一条提示词 → 队列时逐组顺序生成（**一组 = 一张图**）
- 勾选「自动用最新文件」= 每次队列自动刷新到目录里最新的 txt，无需手选
- 想单独给某组机位：在该组标题行下写 `相机:` 行（低于节点「相机数值」里的组配置优先级）
