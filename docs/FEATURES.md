# 功能详解文档(全功能手册)

本手册基于面板实际运行界面 + 源码整理,覆盖 **LoRA 加载节点** 与 **本地管理面板** 的全部功能模块。

---

## 一、LoRA 加载节点(Anima Batch LoRA Loader)

ComfyUI 工作流里的节点,批量挂载 LoRA:

- **`lora_syntax` 文本框**:直接**粘贴 `<lora:xxx:0.8>` 标签**即可解析进列表,不需要先在面板里挑选;文本与下方列表双向同步,手动改文本也会重新解析
- **触发词**:点 LoRA 名字一键复制它的触发词
- **「本地 LoRA」按钮**:打开可视化浏览窗,递归显示 LoRA 根目录及子目录中的文件,能看到 C 站预览图,**点图即加入节点**;支持分类、置顶、收藏
- **每个 LoRA 独立控制**:
  - 开关(关闭后不参与生成,但保留在列表,方便以后重开)
  - 权重调节:尖括号 **scrubbing**——按住 `<`/`>` 水平拖动鼠标连续调权重(4px=0.05),单击步进 0.05,松开生效;名称放宽显示(CSS ellipsis 兜底)
  - 分类标签(使用次数/触发词小字已移除,悬停名称看预览图+触发词弹窗)
  - 删除、拖拽排序
- **「验证标签」**:检查输入里的 LoRA 本地是否存在,缺的可以一键复制名称去 C 站搜索
- **「提取触发词 / 全部触发词」**:快速取用触发词写进提示词
- **「组」**:把常用 LoRA 组合存成预设,一键切换
- **「× 清空列表」「更新」「面板」**:清空、刷新、跳转本地面板

### TK 可动素体相机(新节点)

这是独立于旧版「TK 相机控制」的新节点,用于通过轻量可动空壳素体观察和确定机位:

- 素体由低面数球体、圆柱和体块程序化组成,无 GLB、纹理、贴图和网络模型资源
- 关节层级提供基础 FK:头、颈、胸腔、腰、肩、肘、髋、膝;手臂和腿每侧只保留两个主要控制关节,末端仍显示手和脚轮廓
- 点击关节后拖拽修改 X/Y,底部 XYZ 滑块修改三轴;支持 A-Pose、T-Pose、重置以及浏览器本地姿势保存/恢复
- 画布拖拽环绕相机,滚轮调距离,滑块调倾斜角和 FOV;快捷机位与旧相机控制的 `pos_x/pos_y/pos_z/roll` 直接对应
- 输出复用 `CameraControlCore`;`camera_meta` 携带 yaw、pitch、distance、roll、FOV、归一化相机参数和完整姿势
- 提示词参数面板提供左右方位、上下方位、距离方位、倾斜角四项权重;距离按远景/全身/中景/近景/特写五档识别,档内权重随距离滑块连续变化;滑块和数字输入以 0.1 为步进,预览与相机提示词算法同步
- 空闲不循环渲染,只在交互/状态/尺寸变化后绘制一帧;删除节点时释放几何体、材质、渲染器和尺寸观察器

### Anima Trigger Words 触发词管理节点(新增 2026-08)

独立节点,避免 LoRA 节点臃肿,把各 LoRA 的触发词整理成可直接粘贴的字符串:

- **输入 `lora_syntax`**:可连线接收 LoRA 节点输出或手动粘贴 `<lora:name:weight>` 标签;语法变化时卡片列表**全量同步**(语法中删除的 LoRA 会从卡片与输出清除,不残留)
- **卡片列表**:每个 LoRA 一张卡,触发词可手动编辑(逗号分隔)、可删除卡片
- **「提取触发词」**:批量从 Civitai 查询各 LoRA 的 trainedWords 填入卡片
- **「复制全部」**:把所有触发词复制为逗号连接字符串(可直接贴进提示词)
- **输出 `trigger_words`(STRING)**:自动合并各卡触发词 + 手动补充,去重保序,供 CLIPTextEncode 等使用
- **面板联动**:面板「发送到 ComfyUI」的 LoRA 触发词 ≤5s 自动同步(bridge 轮询);bridge 清除后持久化文件同步删除,重启不复活旧数据

## 二、本地 LoRA 管理(面板 · 默认首页)

管理本地全部 LoRA 文件,Steam 风格界面,分 **首页 / 详情** 两种视图。

### 工具栏
- **扫描文件夹**:递归扫描选定目录及其子目录中的 LoRA 文件(.safetensors/.pt/.ckpt/.pth/.bin),并保留相对路径以区分同名文件
- **子目录建分类**:按一级子目录名称自动创建/复用分类,并把对应 LoRA 归入分类;重复点击不会重复添加
- **URL 下载**:通过 URL 下载 LoRA
- **全部匹配**:把本地 LoRA 与 C 站信息自动匹配(名称/大小/SHA256/下载/点赞/版本)
- **清空 / 批量分类**:清空匹配结果、批量归类
- **搜索**(文件名、模型名)+ **排序**(名称 A-Z)+ **筛选**(全部/已匹配等)

### 统计卡片
- LoRA 总数 · 已匹配 · Outputs 总数 · 关联 LoRA(实时统计)

### 首页视图(网格)
每个卡片显示:预览图、模型名(中英)、本地路径、版本号、作者标签、分类标签(人物/风格/光影…)

### 详情视图
点任一模型进入,右侧面板:
- **文件信息**:文件名、大小、SHA256、基础模型、版本(ID)、下载数、点赞数
- **我的备注**:写下使用心得、推荐搭配、注意事项
- **触发词(Prompt)**:展示并可直接编辑
- **分类标签**:添加/移除分类(人物、风格、背景、姿势、光影…)
- **LORA 标签**:显示调用格式 `<lora:xxx:1.00>`,带强度滑块,一键**复制**
- **操作按钮**:CIVITAI(打开 C 站原页)、COMFYUI(加入工作流)、删除文件
- **关联出图**:查看该 LoRA 用过的返图,右下角一键跳进 Outputs

## 三、LoRA 探索(面板)

浏览 C 站 LoRA 数据(Anima 生态,筛选:下载量 > 250、赞/下载比 > 5%):

- **搜索**:名称、描述、标签、作者
- **筛选维度**:下载量排序、分类、模型类型、时间范围(全部/本月/本周)
- **按钮**:抓取全部(批量加载)、选择(多选模式)、自动翻页、手动添加(URL 添加)
- **分类 tab**:全部 / 画师风格 / 人物角色 / 美学优化 / 背景环境 / 其他 / 收藏 / 已隐藏
- **随机**:随机挑一个
- 卡片操作:检测本地是否已有、直接下载

- **分类**:全部 / 预设

## 五、PROMPT 库(面板)

存档和复用提示词:

- **分类**:全部 / 未分类 / 人物 / 画师风格 / 背景环境 / 光影氛围 / 细节增强 / 常用(可自定义)+ 新建分类
- **搜索**:Prompt、标签、模型
- **条目展示**:关联图片、正向 Prompt、负向 Prompt、保存日期、收藏星标
- **操作**:复制 PROMPT、编辑、删除;右上角 **+ 新增 PROMPT**
- **入口**:图片解析页「保存到 Prompt 库」一键存入

## 六、图片解析(面板)

拖进一张 ComfyUI 生成的原图,逆向出全部参数:

- **上传**:拖拽或点击上传 PNG
- **统计范围**:基于最近 N 张图片(下拉选择)
- **解析结果**:
  - 正向 Prompt / 负向 Prompt(完整原文)
  - 模型、采样器、步数、CFG、种子
  - 工作流(可下载)
- **操作**:复制全部、翻译全部、**发送到 Outputs**、**保存到 Prompt 库**、**下载工作流 .json**、去 Prompt 库
- **高频词统计**:基于最近 N 张返图统计常用 tag,辅助写提示词

## 技术架构(给开发者)

```
浏览器(面板 SPA,Vite + TypeScript)
   │  fetch /anima/* API(HTTP + JSON)
   ▼
ComfyUI 后端(Python)
   ├─ __init__.py        路由:模型扫描 / 元数据 / C 站代理 / 下载
   ├─ anima_batch_lora.py 节点逻辑(LoRA 解析、批量应用)
   └─ web/js/            节点前端(ComfyUI 扩展)
```

- 面板是**纯前端 SPA**,部署在 `app/`(构建产物),数据全靠 ComfyUI 的 `/anima/*` API
- 节点前端 `web/js/` 直接运行在 ComfyUI 页面里,不用构建
- C 站 / Danbooru 请求走本地代理(自动探测),避免超时
